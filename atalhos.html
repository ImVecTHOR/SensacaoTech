⌨️ Atalhos de Teclado

Uma cola rápida para atalhos úteis de programas e sistema.

VS Code

  • Ctrl + A — Selecionar tudo
  • Shift + Alt + F — Formatar documento
  • Ctrl + P — Buscar arquivo rápido
  • Ctrl + Shift + P — Paleta de comandos
  • Ctrl + / — Comentar linha
  • Alt + ↑/↓ — Mover linha

Navegador (Chrome/Brave/Edge)

  • Ctrl + T — Nova aba
  • Ctrl + Shift + T — Reabrir aba fechada
  • Ctrl + W — Fechar aba
  • Ctrl + L — Focar na barra de endereço

Windows

  • Win + V — Histórico de área de transferência
  • Win + Shift + S — Captura de tela
  • Alt + Tab — Alternar janelas
  • Win + D — Mostrar área de trabalho
